# 리모리 (Remory) — 망각곡선 단어장

**Remory**는 **REMEMBER + MEMORY**에서 따온 이름입니다.

영어 단어부터 자격증 개념까지, 기억하고 싶은 내용을 카드로 만들고 예정된 복습일에 다시 만나는 모바일 중심 학습 앱입니다. **Dreamy Memory Garden**을 콘셉트로, 구름새 몽이와 함께 복습하고 학습 기록이 쌓일수록 기억의 정원을 키워요.

## 주요 기능

- **카드 만들기** · 질문과 답, 단어와 예문, 빈칸 채우기, 객관식 네 가지 유형을 지원합니다.
- **일괄 등록** · 스프레드시트에서 카드 데이터를 복사해 한 번에 등록할 수 있습니다.
- **학습 덱** · 외국어, 개발, 역사, 일반 유형에 따라 아이콘과 기본 색상이 정해집니다. 선택한 색상은 카드 미리보기와 복습 화면에도 적용됩니다.
- **간격 복습** · 복습일이 된 카드를 다시 만나고, 기억한 정도를 네 단계로 평가해 다음 복습일을 정합니다.
- **학습 기록** · 최근 7일의 학습량을 확인하고, 복습 횟수에 따라 정원이 자라는 모습을 볼 수 있습니다.

## 실행하기

```bash
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다. 배포용 파일은 `npm run build`로 생성할 수 있습니다.

## 기술 스택과 구현 범위

React 19, TypeScript, Vite, Lucide, vite-plugin-pwa를 사용합니다. 현재 프런트엔드에서는 덱과 카드, 복습 기록을 브라우저의 `localStorage`에 저장합니다. 복습일은 평가별 고정 간격으로 계산합니다.
